## 二、v3 自动化底座一览

### 2.1 确定性脚本（`scripts/`）

| 脚本 | 用途 |
|------|------|
| `state.py` | 批次 state.json 读写封装（init/show/next/set-chapter/set-batch） |
| `pipeline.py` | 章级 DAG 调度器（status/next/tick/advance） |
| `check_dod.py` | 章级 Definition of Done 硬 gate（7 项） |
| `check_format.py` | 章节格式铁律硬检查 |
| `check_seam.py` | 章际衔接检查（β 微提醒规则） |
| `check_facts.py` | canon/事实表 一致性校验（支持 F.delta 合并） |
| `check_tropes.py` | 烂俗套路对抗测试（来自 framework/07） |
| `check_voice.py` | 长期风格漂移探针（句长/对话比/口癖命中率） |
| `scan_ai_templates.py` | AI 味确定性预筛（已读 config/exempt_chapters.yaml） |
| `parse_chapter.py` | 章节解析包（parse.json，供审查 subagent 共读） |
| `propose_lexicon.py` | AI 词库自增殖建议 |
| `batch_report.py` | 批次完成报告自动生成 |
| `cleanup_drafts.py` | Best-of-N 中间稿清理 |
| `gen_reader_prompts.py` | 读者模拟 prompt 批量生成（已内置 RETURN_JSON） |

### 2.2 主 agent 每轮循环（mantra）

```bash
# 1. 看当前状态
python3 scripts/pipeline.py status <batch>

# 2. 跑一切可自动化的步骤（扫描/DoD/facts 检查）
python3 scripts/pipeline.py tick <batch>

# 3. 查询下一步派谁
python3 scripts/pipeline.py next <batch>
# → 输出 JSON，列出此刻可并发派发的 subagent 清单
```

### 2.3 升级边界合同（`framework/08`）

主 agent 何时停下来问用户：见 `framework/08_自动升级规则.md` 三十条规则。
简言之：
- 写作重试 ≥ 2 次失败
- DoD gate 连续 2 次未过
- canon 冲突（身高/生日/不可变字段）
- 读者平均分 < 5
- 脚本链关键崩溃（state.py 写不进去 / check_dod crash）

其余情况主 agent 自决，不打扰用户。

- ❌ 旧"修订完人眼确认" → **v3 `check_dod.py` 硬 gate**，未过自动再派一次修订。
- ❌ 旧"事实表只有 markdown" → **v3 双份**：`审查/事实表.md`（人读）+ `审查/facts.json`（机读，`check_facts.py` 校验 canon）。
