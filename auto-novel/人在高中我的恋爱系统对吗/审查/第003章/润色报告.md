# 《第 003 章 客人》润色报告

> 审查维度：⑤ 节奏 / ⑥ 重复 / ⑦ 文风统一 / ⑧ 去 AI 味（核心） / ⑨ 可读性。
> 本章中文字数 3108，字数不达标。本报告 D 段给出约 700 字的补扩落点与"不写成女童俗套"的具体动作指南。

## A. 硬错误（必须改）

> 本报告不主审硬错误，详见《硬校验报告》。此处只标润色类"硬伤"。

- **A1.（润色范畴）结尾"过电影式"回忆清单** 第 441–453 行："闭上眼睛的那一瞬间，脑子里最后过了一遍今天发生的所有事。早上第一天进教室。同桌。'早。'林知夏细框眼镜后面那一双眼。老陆的秃顶。周胖的大嗓门。郑维那副'按理说'的腔调。放学。我妈的短信。进门，鞋架上那双粉白色的小运动鞋。'陈屿哥哥……'"
  → 问题：**典型 AI 味"章末闪回清单"**。八九个名词短语排队列出，从上学到进门全列一遍，属于"章末总结式收尾"的变种。读者本章刚看完这些事件，不需要再被重播一遍。
  → 改写方向：整段删掉，只保留"进门，鞋架上那双粉白色的小运动鞋。'陈屿哥哥……'"两行，其余清单全砍，用身体小动作替代（见 D 段落点 e）。

- **A2.（润色范畴）结尾三重"晚安"收尾** 第 527–537 行："【晚安，对吗？】（……）（晚安个头。）（……）（晚安。）"
  → 问题：三行递进式"晚安"属于"模板型章末收束"，加上前面那段回忆清单，连续两个模板段位，收尾过满。
  → 改写方向：保留"【晚安，对吗？】""（晚安个头。）"两行，删掉最后一行单独的"（晚安。）"，或把它改成**一个身体动作**（例如"我翻过身去。台灯还亮着。"）。

## B. 软问题（影响阅读体验）

- **B1. [节奏] 结尾从"脑子里最后过了一遍今天发生的所有事"到"（晚安。）"共 60–70 行**（第 441–537 行），信息密度偏低——铺了**三次**睡前场景（第一次躺下看水渍→第二次系统预告→第三次闭眼回想），每一次都在"脑海又响起陈屿哥哥"。建议砍掉中间一次，让结构变成"躺下→系统预告→闭眼→身体动作→关灯 / 不关"两段。
- **B2. [重复] "陈屿哥哥"在陈屿脑海里反复跳**：第 355–357 行"'陈屿哥哥。'那四个字，又自己在我脑子里跳了一下"已经做了"脑海回响"这件事，章末第 497 行又来一次"我脑子里最后一句响起来的，还是那一句——'陈屿哥哥。'"。**章内同一意象用两次**是允许的；但第 497 行前面还有 4 句"过电影式清单"+ 后面还有 4 行"麻花辫甩了一下 / 小雀斑 / 伸到一半的手 / 头也不回的炭头"四连并置——一章里"陈屿哥哥"这个小钩子被用了 **3 次**。建议章末只留一次，放在身体动作之后（见 D 段落点 e）。
- **B3. [重复 · 脸红]** 脸红出现 3 次：第 59 行 "她的脸很慢很慢地红了一下，从耳朵尖开始"；第 185 行 "阮眠的脸又红了一下"；第 169 行附近 "长长的睫毛颤了颤"（虽不是脸红，但属于同族女童生理反应堆砌）。建议**保留第 59 行那次**（登场一脸红是可接受的锚点），把第 185 行"脸又红了一下"换成动作——例如"她咬了一下筷子头"或"她夹菜的手停了半秒"。
- **B4. [节奏 · 排比四并]** 第 501–507 行 "麻花辫甩了一下。小雀斑。伸到一半的手。头也不回的炭头。"
  → 风格铁律第 130 行"排比最多两并，不三并"。这里是**四并**，直接破规。建议压成 2 条，保留最具体的两个："伸到一半的手。头也不回的炭头。"——两条都是这一章真正发生过的动作，省掉意象堆砌味。
- **B5. [节奏 · 系统段落节奏]** 第 395–425 行 系统预告第 004 章那一大段对话（"下周二第二节课……""本系统任务栏已预留位置……"）**硬校验已要求改时间**（A1），同时润色角度这一大段偏长。建议把系统与陈屿来回三轮压成两轮，让"系统提前爆料"这个设定冲击更脆。
- **B6. [信息密度 · 妈妈那句绕句]** 第 49 行 "我跟阿姨一个单位——哦不，是你阿姨以前跟我一个单位"。搭配后一句"我妈说话一向自己能把自己绕进去"，作者意图做"妈妈絮叨"的风格，效果可以，但**信息没交代清**（见硬校验 A2）。建议按硬校验 D2 改写之后，保留一点妈妈絮叨的味，但一句话交代完托付来源。
- **B7. [文风统一]** 整章第一人称 + 括号心声 + 方括号系统三种格式守得住，与 001–002 章基调一致 ✅。阮眠进门 → 晚饭 → 洗碗 → 撸猫 → 睡觉这条线本身干净，第 233–329 行（洗碗 + 阳台撸猫）是全章最像"这本书"的部分，应作为修订时的**节奏锚段**保住。

## C. AI 味句段（直接标出原句 · 重点查"女童模板"）

> 本章整体 AI 味程度：**中**。集中来源是"阮眠出场时的女童生理反应模板堆"。按用户指示逐条列出原文：

- **C1. 原句（第 169 行）**：阮眠抬了一下头，**长长的睫毛颤了颤**："云屿外国语，初三（2）班。"
  → 问题：**"长长的睫毛颤了颤"是头号女童模板**，与"她眼中闪过一丝"同属黑名单兄弟句式。而且"睫毛颤"这个动作几乎是 AI 写小女孩时最先冒出来的套路。
  → 改写方向：换成一个具体的"紧张但克制"的动作。例："阮眠抬了一下头，手指把筷子头捏紧了一点，'云屿外国语，初三（2）班。'"或"她低头数了两秒，才'云屿外国语，初三（2）班。'"——**去睫毛化**。

- **C2. 原句（第 193 行）**："像一只**被摸了一下脑袋就缩回壳里的小动物**。"
  → 问题：俗套动物喻（乌龟 / 小兔 / 小松鼠类），且是对一个 15 岁女生的**幼化比喻**——正是用户要求重点防的"女童模板"。阮眠人设是"保送线的聪明孩子"，写成"缩壳小动物"会矮化她。
  → 改写方向：去喻体，给动作。例："一被夸，就说'我不是'。她说完又低头扒一口饭，像是把自己重新藏回碗里。"（"藏回碗里"是具体空间动作，不是动物喻）。

- **C3. 原句（第 281–283 行）**："那双**圆眼睛里有一点点委屈，还有一点点——我说不出来的东西**。"
  → 问题：**"过度解释情绪"+"眼睛里有光/委屈/说不出来的东西"** 三重模板合体。陈屿作为 POV 替阮眠情绪做了**两层**主观解读，直接把阮眠写成了"可怜惹人爱的小女生"。
  → 改写方向：删掉第二层（"还有一点点——我说不出来的东西"），只留第一层委屈，并让陈屿**看见她把委屈收起来**。例："那双圆眼睛里委屈了半秒——然后她自己把它咽下去了，抬头冲我笑了一下。"——**失望一瞬间立刻收起来**，正好对应硬校验 D6 要求的"聪明不较真"。

- **C4. 原句（第 307–309 行）**："她笑起来的时候，**眼睛弯成两个小月牙**，左边脸颊有一个**很浅的酒窝**。然后她好像意识到自己笑得太明显了，又立刻把嘴抿回去。"
  → 问题：**"小月牙眼 + 酒窝"女童模板双连**。任何轻小说都在这么写女童笑。且第 307 行与下文 309 行"立刻把嘴抿回去"动作很好，却被前半句"月牙 + 酒窝"抢戏。
  → 改写方向：删掉"眼睛弯成两个小月牙，左边脸颊有一个很浅的酒窝"那一整句，直接从"她笑起来的时候"跳到"好像意识到自己笑得太明显了，又立刻把嘴抿回去。"——留动作，删定妆。阮眠的"娃娃脸"已在第 45 行一次性描过，这里不用再上定妆镜。

- **C5. 原句（第 361 行）**："它跳的时候，带了一点点**软软的气音**，像**一片羽毛从耳朵边擦过去**。"
  → 问题：**"羽毛擦过耳朵"**是经典俗套喻体（与"声音像风铃"同源）。而且这里是"'陈屿哥哥'四个字在陈屿脑中跳"的内心化——用外部物象（羽毛）来比喻脑中响起的声音，层次上也别扭。
  → 改写方向：去喻体，改身体反应。例："它跳的时候，我的后槽牙咬了一下。"或"它跳了一下，脑后的小包闷闷地应了一下。"——把声音的"软"换成**身体被提醒**的具体反应。

- **C6. 原句（第 101 行）**："我妈笑她：'你这孩子，**胆子跟麻雀似的**。'"
  → 问题：轻度俗套比喻（"胆小如鼠 / 麻雀"家族），单用可过，但与 C2"缩壳小动物"+ C1"睫毛颤"同页出现会形成"小动物 + 小动物 + 小动物"的**女童堆料**。
  → 改写方向：本句由妈妈说出口，日常口语可接受，**保留可**。但若 C1 / C2 不改，建议这一句也换——比如"你这孩子，吓一下就缩回去"（动作化）。

- **C7. 原句（第 491 行）**："我闭着眼，**嘴角居然翘了一下**。"
  → 问题：**"嘴角微扬"家族**的弱化版。虽然是"翘了一下"不是"微扬"，但性质相同。
  → 改写方向：改成具体动作。"我闭着眼，把枕头往下拽了半寸。"或干脆删这一行——让读者自己去感觉陈屿是笑了还是没笑。

- **C8. 原句（第 441–451 行，过电影式回忆清单）**：已在 A1 详述，属于典型"章末总结式"AI 味。

（AI 味严重度统计：女童模板 **4 条**（C1/C2/C3/C4）+ 俗套喻体 **2 条**（C5/C6）+ "嘴角类"模板 **1 条**（C7）+ 过电影清单 **1 段**（A1），共 **8 处**。本章字数 3108，密度约 2.5 条/千字，判定为**中度 AI 味**，改完后可达"轻"。）

### D-补扩部分（补约 700 字 · 按用户指定 (a)–(e) 五落点）

> 分配建议：总预算 700 字；(a) 120 / (b) 200 / (c) 150 / (d) 130 / (e) 100，**留 0 字给 D1–D4 的压缩盈余顶回去**。

- **D7. 落点 (a)：楼道 / 开门前**（约 120 字 · 插在正文第 3–7 行之间）
  - **要写**：开学一天下来的疲惫（书包带压肩 / 小腿酸）；系统今天"她是假装信，对吗？"这句还在脑里晃；四楼楼道声控灯坏那一盏，陈屿拍两下没亮，干脆摸黑上；手放在门把上停半秒，隔着门闻到炖肉味——这味**不对**，他家周一从不炖肉。
  - **不要写**：不要抒情（"开学第一天的夕阳温柔地……"——坚决不要）；不要"心里涌起一种难以言喻的……"。
  - **示范句骨**（供修订 subagent 参考）：
    > 四楼那盏声控灯坏了，我拍了两下，灯丝嗡了一声，又熄。/ 我摸黑上到四楼。书包带把左肩压了一天，这会儿还沉沉的。/ 手指刚碰到门把手，我停了半秒——门缝里飘出来的不是我妈的咸菜炒肉丝味。/ 是炖肉。/ （我家周一从来不炖肉。）

- **D8. 落点 (b)：陈屿洗碗时偷听妈妈与阮眠妈妈通电话**（约 200 字 · 插在正文第 227–231 行之间，"水声哗啦啦响起来" → "我洗完最后一只碗"之间）
  - **要写**：
    - 水声开着，**半掩**妈妈在客厅打电话的声音。
    - 陈屿只听到几个词："嗯——吃了，吃了。""你跟老阮路上慢点。""小阮在我这儿，放心。""项目先顾着，回头再说。"——信息点：出差 / 父亲工作偏忙 / 电话托付方向（阮妈 → 陈妈）。
    - 妈妈挂电话的动作（从沙发扶手起身 / 把手机放进围裙口袋）。
    - 陈屿听到"小阮"这两个字时**手停了一下又接着洗**——这是他对"家里多了一个人"的第一个生理反应。
  - **不要写**：不要让陈屿心里长篇展开"原来阮眠家是这么个情况……"；不要明确说阮眠爸妈职业（保留留白）；不要出现阮眠站在门外偷听之类的戏剧化桥段。
  - **示范句骨**：
    > 水声开着，厨房隔出一小片白噪音。/ 客厅那边我妈拿着电话："嗯——吃了，吃了，就刚吃完。"/ "你们几点的飞机？……行，那路上慢点。"/ "小阮在我这儿，你们别惦记。项目先顾着。"/ （老阮。项目。）/ 我洗到一只沾糖醋的碟子，手指在碟子边缘停了一下，又接着洗。

- **D9. 落点 (c)：饭桌菜色 / 阮眠夹菜小动作 / 炭头跳上椅背冷处观察**（约 150 字 · 扩第 139–147 行之间）
  - **要写**：
    - 一道家常小菜：建议"凉拌木耳"或"蒸蛋"——选"蒸蛋"可以自然让阮眠小声说一句"好呀"来呼应口癖。
    - 阮眠够不到远处的菜（比如番茄蛋汤在陈屿这侧），陈屿**不说话**把汤碗推近半寸。
    - 炭头从沙发底下慢慢踱出来，跳到**靠窗那只餐椅的椅背上**（不蹲在阮眠旁边，也不在陈屿脚边），尾巴垂一下，**只看不靠近**。这个细节为后文撸猫失败垫好"它从一开始就保持距离"。
  - **不要写**：不要写阮眠夹菜"嘴角带着甜甜的笑"之类；不要让炭头做"可爱动作"。
  - **示范句骨**：
    > 桌上多了一盘蒸蛋，黄色在碗里微微抖。我妈把蒸蛋推到阮眠面前："趁热。"/ "好呀。"阮眠小声说。/ 她舀了一勺，没舀满；番茄蛋汤的碗在我这头，她够了一下，手收回去。/ 我把汤碗往她那边推了半寸。/ 她愣了一下，说了声"谢谢陈屿哥哥"。/ 炭头不知什么时候从沙发底下出来了，跳上靠窗那只餐椅的椅背，蹲在冷处，尾巴垂一下——不看人，也不靠近。

- **D10. 落点 (d)：阳台撸猫失败 · 具体动作 · "聪明不较真"落地**（约 130 字 · 扩第 277–291 行"阳台上的阮眠保持着伸手的姿势"那一段）
  - **要写**：
    - 炭头从手边绕过去 → 阮眠的手**僵半秒** → **手指收回的速度比伸出去快一点点**（这是全书第一次让读者看到阮眠"聪明"的证据：她知道失败了，马上收场）→ 脸上一瞬间的失望 → 她**不让它停留**，反过来转脸冲陈屿笑了一下 → 说"它不喜欢我，没事。"
    - 陈屿看见这条完整的"收场链"，心里记了一下，但**不评价**。
  - **不要写**：不要"她眼里闪过一丝失望"；不要"她委屈地看着我"；不要让阮眠**追问**"陈屿哥哥它为什么不喜欢我"。**她不该追问**，这就是她"聪明"的证据。
  - **示范句骨**：
    > 她的手还停在半空。/ 过了半秒，她才把手收回来——收回来的速度比伸出去的时候快了一点点。/ 她低头看了看空空的掌心。/ 失望在脸上停了一下，像一阵风过去。/ 她抬头冲我笑了一下："它不喜欢我。没事。"/ （……"没事"这两个字说得太快了。）/ 我没接话。

- **D11. 落点 (e)：夜里陈屿想"陈屿哥哥"这个称呼 · 只给身体小动作**（约 100 字 · 扩第 357–373 行之间；**严格不抒情**）
  - **要写**：**一个**身体动作，选一。候选：
    - ① 翻身，脸压进枕头，闻到洗衣液味。
    - ② 脚趾在被窝里蜷了一下，又放平。
    - ③ 伸手摸了摸后脑那个已经不疼的小包。
