# 《第 008 章 青梅来了》审查报告（润色）

> 审查维度：5 节奏与篇章结构 / 6 信息密度与重复 / 7 文风统一 / 8 去模板化（核心）/ 9 可读性与感染力

---

## A. 硬错误（必须改）

> 本段归硬校验 subagent 管辖，此处不重复。参见《硬校验报告.md》A1（第 007 章末"苏叔周五回来 / 周六在家"钩子失接）。

## B. 软问题（影响阅读体验）

- **B1. 节奏——开头铺陈"梦游/糊"过久。** 从第 3 段"三月的风从山那边翻过来"到第 39 段"（……玉兰开了。）（……我居然注意到玉兰开了。）（……梦游第五日的副作用，大概是回光返照。）"，约占全章前 1/7 篇幅在演"陈屿今天很糊"。本章任务是"青梅登场 + 关东煮 + 烧书威胁"，前戏略长。建议砍 20–30 字："被水泡过"那句可以留，连续三个"（……）糊"的碎段（第 25 段"就是糊"到第 30 段系统汇报哈欠）压成两段。

- **B2. 节奏——中段苏檐邀约后的"全班反应"拆得稍碎。** 从"全班视线'唰'一下聚到我身上"到"耳朵真的很难装死"之间，穿插了郑维、林知夏翻书、后排女生议论、系统"几何"插科打诨四段。四段各自精彩但并列平铺，没有层次。建议把系统"几何"那一小段和下面"中午食堂"之间的分隔处理得更干净（比如减一次"已'好'"式 meta 对话，避免在同一场景连用三轮）。

- **B3. 尾段心声回环密度偏高。** 从"出了校门又回头看了一眼"到章末（即"不代表什么……五遍了"+"下午两点 / 老场 / 《海底两万里》 / 黄色皮那本 / 封底 / 我要不要今晚翻一下封底 / 算了 / 翻了就掉进她的圈套 / 但不翻 / 两年半 / 够久了"），连续约 20 行全是括号心声独白。**这一段是全章最重的情绪高点**，需要保留，但节奏过快的同构括号短句（"……老场。""……《海底两万里》。""……黄色皮那本。""……封底。"）四连用形成节拍型抒情，接近"三连叠 / 四连排"的边界。建议把这四句拆成一个短段 + 一个含具体动作的长句，比如："（……老场。下午两点。她点的是那家要烧我书的黄皮《海底两万里》的老场。）"—— 同样的内容，节奏就从鼓点变成叙述。

- **B4. "梦游"关键词重复 5 次。** "梦游五日 / 梦游第五日 / 跟个梦游一样（苏檐）/ 跟梦里说话似的（苏檐）/ 梦游（陈屿自言）"。这是精心设计的回环笑点（自己骂自己→青梅骂自己→青梅骂得更狠→自己承认），基本面是好的，但第 1 处"（……梦游五日，今日第五日。）"稍刻意，可以直接改为"（……第五天了。整整第五天。）"，让苏檐后续那句"你这几天跟个梦游一样"单独成为第一次"梦游"定性。读者会觉得更爽。

- **B5. 对话密度合格但"省略号开头的短回应"过密。** 全章陈屿对苏檐的回复几乎全部是"……X"格式（……谢了 / ……我没有 / ……我哪有说过 / ……噢 / ……我知道 / ……到 / ……来 / ……），密集出现在校门口 + 教室门口两场戏。陈屿寡言 + 被压着 = 这个格式对，但**连续 8 次以上**会形成机械节拍。建议中间至少换两处用"动作代回应"（如"我把袋子重新挪了个位置"、"我咽了一下"）打断节拍。

## C. AI 味句段（直接标出原句）

> 本章整体 AI 味**很轻**，大部分描写颗粒度接近风格锚章（001、002、007）。以下是仅有的几处需要标注的。

- **C1. 原句**："马尾在三月的空气里甩出一个弧。/阳光斜斜地落在操场半幅。/另半幅在云的影子底下，灰一点。/她站在亮的那边。"
  - 问题：四行短句叠成一个"阳光+她+站位"的文艺抒情片，末句"她站在亮的那边"是典型的 AI 抒情收束（对应手册 §8"总结式收尾""俗套喻体"的边界外延）。单拎它本身不错，但和前三句连用就变成"MV 定格"。
  - 改写方向：保留前三句写景，把"她站在亮的那边"换成具体动作——例如"她在亮的那边又故意往后栽了半步"。既保画面又落在动作上，比"站在亮的那边"的静态宣言更有人物感。

- **C2. 原句**："风卷着笑声穿过玉兰树，飘出校门，散在巷口。"
  - 问题：三连动词（卷、穿、飘、散）+ 环境扫描，属于"套路转场"类 AI 味环境抒情。本章开头已经有过"三月的风从山那边翻过来，贴着领口往下灌。"那句写得极好、极具体；这一句相对空、可替代。
  - 改写方向：换为带角色声音的收束——"玉兰树底下那一群人还在笑，风把那个笑切成一段一段，跟上午一样。"把"散在巷口"这种概念化抒情改成"跟上午一样"这种回指，读者自然关联上午校门口关东煮那一刻。

- **C3. 原句**："我听见自己的声音飘在半空。"
  - 问题："声音飘在半空"是高频AI抒情比喻（类同"心跳漏了一拍"梯度）。虽只出现一次，但属"情绪模糊化"写法（手册 §8 "过度解释情绪"变体），破坏陈屿本章一直很克制的物理感。
  - 改写方向：改为具体生理反应——"我听见自己'谢了'两个字轻得像没说出来。"或"我自己都没听清这声'谢了'是不是真发出来了。"——用动作/感官替抒情。

- **C4. 原句**（中度，边界）："三月的风贴着领口往下灌。"（开头）+ "三月的风贴着玻璃走。"（第 007 章末尾类似 + 本章仅一次类似 "云屿三月就是这样，早上冷，中午暖，傍晚又捡回半截凉。"）
  - 问题：不是 AI 味（写得不错），但"三月的风"作为环境锚词在 007 和 008 两章内部共出现 4–5 次，开始形成**风格层的重复**。
  - 改写方向：本章保留头尾 2 次，删掉或改写中段第 3 次（车棚那段的"风比早上大一点"前后可省一个）。润色层建议，不是错。

- **C5. 原句**："后脖子开始发紧。"
  - 问题：不是 AI 味。反而是陈屿少有的具体生理反应，**记忆点**，留着。此处列出是作为 B 级正面示例——告诉修订 subagent 不要把这种"具体疼痛感"改掉。

（以上 C1–C3 为需要直接改写的三处；C4 为建议减一次；C5 为保留示例。）

## D. 修改建议（不是泛论，要具体）

- **D1.【C1 配套】** 把"马尾在三月的空气里甩出一个弧。/阳光斜斜地落在操场半幅。/另半幅在云的影子底下，灰一点。/她站在亮的那边。"改为：

  ```
  马尾在三月的空气里甩出一个弧。
  阳光斜斜地落在操场半幅，另半幅在云的影子底下，灰一点。
  她在亮的那边又假装要去抢球，故意往后栽了半步。
  ```

  把"站/灰"意象点到为止，落在具体动作上。

- **D2.【C2 配套】** 把"风卷着笑声穿过玉兰树，飘出校门，散在巷口。"改为：

  ```
  玉兰树底下那一群人还在笑，风把那个笑切成一段一段，跟早上校门口一样。
  ```

  呼应开头"玉兰的第三枝开了一小簇白"，形成首尾环。

- **D3.【C3 配套】** 把"……谢了。"我听见自己的声音飘在半空，"……谢谢。" 改为：

  ```
  "……谢了。"我自己都没听清这声是不是真出去了，顿一下，"……谢谢。"
  ```

- **D4.【B1 配套】** 删节开头"就是糊。/（……梦游五日，今日第五日。）"到系统"打哈欠 27 次"这一串，压到以下版本：

  ```
  （……第五天了。）
  （整整第五天了。）

  【宿主早上好，对吗？】
  （……早。）
  【本周您完成任务 3 条，任务失败 1 条，被炭头骚扰 5 次。】
  （你连炭头都记？）
  【顺便的，对吗？】
  ```

  省下 40–60 字，给 A1 硬校验补的苏叔钩子腾出字数。

- **D5.【B3 配套】** 结尾"下午两点。/……老场。/……《海底两万里》。/……黄色皮那本。/……封底。"五连短句心声重组为：

  ```
  （……下午两点，老场。）
  （……黄皮《海底两万里》，床头柜第二格，封底她两年半前写的那一行。）
  （我要不要今晚翻一下那一页。）
  （……翻了就掉她圈套了。）
  （不翻，我看台上一定一直惦记。）
  ```

  节拍从"鼓点"变成"呼吸"，画面不丢。

- **D6.【B5 配套】** 校门口关东煮场景中，把陈屿其中一次的"……X"回应改为动作。例：

  ```
  "……谢了。"
  "嗯。"
  她双手一插兜，后退半步，抬下巴打量我。
  "你这几天跟个梦游一样。"
  我把袋子往怀里紧了紧。（← 用动作回应，不再说"……我没有。"）
  "你说的。"
  ```

  再保留后面"……我哪有说过。"就够了，连发 3 次"……X"改为 1 动作 + 1 回话更有节奏。

- **D7.【B4 配套】** 开头把"（……梦游五日，今日第五日。）/（……梦游第五日的副作用，大概是回光返照。）"两处"梦游"去掉（第 1 次和第 3 次），让"梦游"这个词**第一次出现**是苏檐嘴里"你这几天跟个梦游一样"——破冰效果最强。

## E. 风险预警（给后文埋的坑）

- **E1.【文风 · 监控】** 本章陈屿心声中"不代表什么"重复 5 次并自嘲"这四个字我今天已经在心里说了五遍了"——这个自嘲式 meta 心声是好记忆点，但它是**一次性使用**的招式，后续章节如果陈屿再用"我今天在心里说了 X 遍 Y"这种结构，会立刻从巧妙变成套路。记入风格监控。

- **E2.【节奏 · 监控】** 本章结尾情绪高点（"两年半 / 够久了 / 我今天早上才第一次从她手里接过一袋关东煮"）已经把苏檐线的情绪张力拉到卷一前半段的顶格。**第 009 章球场戏 + 第 010 章阮眠讲题**两章必须是节奏缓冲章，不能再在陈屿心声里做"又一次深度凝视"；否则会反噬 008 的余味。已通知 009 章审查 subagent 注意。

- **E3.【记忆点 · 正面】** 本章记忆点有三：① "陈屿，你是不是傻。"（从七岁一字未改）② "一点都不英气。像一个十五岁半的家伙。" ③ "萝卜、鱼丸、海带结。没要油豆腐，油豆腐你从小不吃。"。建议修订 subagent **不要触碰**这三处，包括它们周围的标点与换行。

## 总评

- **AI 味严重度**：**轻**（全章仅 C1–C3 三处需改写，无一处踩中"她不由得 / 嘴角微扬 / 心跳漏了一拍 / 不知过了多久 / 刹那间 / 莫名其妙地 / 她眼中闪过一丝 / 就这样……"红线）
- **文风统一度**：与 001/002/007 锚章对齐，陈屿第一人称、对话密度合格、心理"括号体"格式一致。
- **可读性 / 感染力**：优。记忆点 3 个，结尾余味到位，苏檐登场的画面有冲击力（烫掌心的塑料袋 / 马尾 / "烧了"）。
- **是否需要第二轮审查**：否（按 D1–D7 修订，改动字数 ≤ 150，远低于 30% 重写阈值）。
- **一句话综评**：本章是卷一到目前为止气质最锐的一章，苏檐登场的物理温度（关东煮的烫 / 嘴毒的扎 / 马尾的甩）全部给到了；唯有开头"梦游"铺陈偏长、尾段心声节拍偏碎、"她站在亮的那边 / 飘出校门散在巷口"两处微 AI 抒情需替换，其余可放行。
