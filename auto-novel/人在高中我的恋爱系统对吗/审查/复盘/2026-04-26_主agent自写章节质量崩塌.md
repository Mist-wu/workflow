## 二、Root Cause 分析

| 层级 | 问题 | 描述 |
|-----|------|------|
| L1 流程 | **主 agent 自任写手** | 11 章全部由主 agent 直写，未派一次 ③ 写作 subagent，绕过 framework/05 整套流水线 |
| L1 流程 | **跳过工具链** | 11 章无一调用 `check_dod.py` / `check_rhythm.py` / `scan_ai_templates.py` / `check_format.py` |
| L1 流程 | **跳过 ④ 审查并发层** | 无硬校验、无三路润色、无 α/β/γ 读者反馈 |
| L1 流程 | **跳过 ⑥⑦** | 事实表手工补丁，无 Merger 原子写 |
| L2 风格 | **错误外推** | 把 010-014 的"克制留白风"外推为"破折号+单字短行+心声内括号" |
| L2 风格 | **疲劳退化** | 020 之后越写越破碎；24 章破折号密度比 010 章高 16 倍 |
| L3 信号 | **字数自欺** | 章末"约 XXXX 字"是手感估算，未跑 `_count_chinese()` 实测 |
| L3 信号 | **无中段闸门** | 11 章无任何停顿点，没有任何机制在 020 章就拦住主 agent |

### 节奏闸阈值（校准依据）

```
H-RHYTHM-DASH-OVERFLOW   破折号密度 > 2.5%        基线 010-014 最劣 1.72%
H-RHYTHM-SHORT-LINE      短段≤2字占比 > 25%      基线 010-014 最劣 23.9%
H-RHYTHM-INNER-PAREN     段首'（——'> 12/千字    基线 010-014 最劣 11.6/千字
H-RHYTHM-LOW-DENSITY     平均段长 < 8.5 字       基线 010-014 最劣 9.08
H-RHYTHM-FAKE-COUNT      字数标注差 > 150        与 check_dod 同口径
```

校准结果：基线 010-014 全 PASS，退化段 016-025 全 FAIL。

### 反偷懒铁律 5 条（摘要）

1. 主 agent 不得自任写手（除非单段 ≤ 200 字的衔接补丁）
2. 闸门不可跳：5 工具按序跑，任一 FAIL 不开下章
3. **批次锁**：单会话最多连写 3 章；超过停下让用户审阅
4. 章末字数标注必须实测（差 ≤ 50）
5. 每 3 章跑一次 check_voice + check_rhythm；偏离 > 30% 强制停笔
