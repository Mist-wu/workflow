## B. 软问题（影响阅读体验，优先级次于 A）

- **B1. 周三早读是否真的发生过特殊事件？**（连续性）
  - 钩子段让陈屿"回想周三早读"并得出"她僵 / 紧张"的印象，但第 004 章周二晚自习结束后，第 005 章正文只写周三中午起的事，**周三早读作为一段完全未呈现的空白被强行追记**。日常章视角限制（第一人称）允许追忆，但不允许凭空追加从未写过的心理观察。建议：把回忆只锁在"交作业时她给我对齐了格子"这一件真实发生过的小事上。

- **B2. "黑色中性笔"道具与第 004 章道具撞色**（信息辨识）
  - 第 004 章的核心道具是"林知夏那支哑光黑色签字笔"，第 005 章顾星晚递过来的也是"一支黑色中性笔"。两支笔同色同近似款，读者刚读完 004 就到 005，会下意识把两支笔联想成一个东西。建议把顾星晚那支改成具体可识别的样式（如"一支笔帽上套着小夹子的藏青色中性笔" / "一支细杆的银色中性笔"），同时回扣顾星晚"慢一点、规整"的人设质感。

- **B3. 顾星晚"对吗？"的使用频次**（人物一致性 / 风险 · 详见 E1）
  - 她在结尾自然口语地说"三分钟，对吗？"本身没错（"对吗"在中文口语里就是普通疑问词），问题是**陈屿的反应被写得过大**——连问三段"她怎么会用'对吗'？？？"。这让一个梗被拉长到像作者在敲黑板提示读者。软问题：反应段可砍到一次即止。

- **B4. 周胖 / 老陆 / 林知夏的三个配角口癖命中情况**
  - 周胖：任务要求"这学姐声音我老婆都比不了"必须出现 + 三个口癖任意一个命中。正文有"这学姐的声音，我老婆都比不了"（✅），有"兄弟"（✅），"这波啊……" / "我请客"未精确命中但出现变体"我今天请你吃鸡腿"（算擦边命中）。达标。
  - 老陆：本章不正面出场（只被顾星晚转述"老陆班主任在办公室点了你的名"），符合细纲。口癖"你说是吧，陈屿同学"未登场也不强求。达标。
  - 林知夏：本章只是被"路过"和"回家后翻作业本回忆"，没有直接对话，符合细纲把戏份留给第 006 章。达标。

- **B5. 炭头叼袜子开场**（设定一致性）
  - 开场"炭头叼袜子到我胸口"是个可爱细节，但与细纲"周三早上"无事件冲突。不过这已经是本书第三次让炭头开场（001/004 章均有炭头做开场引子），密度略高，不算错，但建议修订 subagent 留心下一章别再让炭头做第一段。

## D. 修改建议（硬校验视角：只给事实性 / 逻辑性建议）

- **D1. 字数补扩 ~650 字，落五点**（与任务书一致，此处只做硬校验视角的动机/事实约束）：
  - (a) 中午广播听觉场景（~150 字）：明确顾星晚的声音从"食堂二楼排队区头顶斜上方那个老式木壳广播"传出来（章内已提"墙上挂的老式木壳广播咯哒响了一声"，补扩时把"在哪面墙" / "饭勺碰饭盆声" / "打饭阿姨吼号" / "陈屿端饭盆的手顿了半秒"写实）。**不得**把她的声音形容成"像春风" / "像泉水"等俗套喻体。

## E. 风险预警（给后文埋的坑）

- **E1. 顾星晚使用"对吗？"的设定边界**
  - 本章首次让顾星晚自然说出"三分钟，对吗？"并让陈屿产生"她会不会知道系统"的错觉。作为钩子很有趣，**但全书只能偶发、不可规律化**。建议整本书顾星晚直接使用"对吗？"的次数**不超过 5 次**，且仅在她主动"逼"陈屿（卷一末 024 章走廊电话段 / 卷六出国前 / 卷八回来 / 卷十毕业）等关键节点出现，避免与系统口癖互相夺权。已登记到风险清单建议项。

- **E2. 指甲印钩子悬空风险**
  - 005 章新增的"作业本上拇指凹印"细节，是作者自创补充（不在卷一细纲内）。第 006 章（已定稿）未回扣。若后续章节也没回扣，读者会遗忘这条细节。建议：
    - 方案 A（推荐）：第 011 章《作业本里的小人》是天然回收点——让陈屿在林知夏画火柴人那一格的附近，再次看见一个淡淡的指甲印，**自然回收**（不是显式解释，而是读者感觉到"这是她的习惯"）。
    - 方案 B：若 011 章不动，记入"悬而未决"清单，后续任意林知夏认真对齐作业的场景回扣一次即可。
  - 本轮修订可以先不动 011，但主 agent 需把这条记入 `审查/风险清单.md` 或事实表"已激活伏笔"。

- **E3. 顾星晚"温柔滤镜"系统性风险**
  - 她的首登戏已经贴了几次"夕阳" / "风吹头发" / "慢半拍"这类偏"圣母学姐模板"的描写。**本章本身尚可接受**（都锚定在具体动作上），但提醒修订 subagent：D 段补扩 (c) 务必"用具体细节不用滤镜"。否则到第 014、016、021 章她每次出场都加夕阳 + 头发 + 慢半拍，会固化成模板女神。风险记录：每三次顾星晚出场，允许使用"夕阳 / 风吹头发 / 浅笑"这组意象**最多一次**。
