## B. 软问题（影响阅读体验）

- **B1. 节奏 · "三分钟"倒数段信息密度偏低**
  - 位置：站三分钟 → 第一分钟 / 第二分钟 / 第三分钟三小节。
  - 问题：第一分钟（读公告细则）和第三分钟（倒数 60/59/58）结构相近，第二分钟（后悔、被路人议论）是最有信息量的。三段读下来，中段紧、头尾稀。
  - 建议：把第一、第三分钟合并（或把第三分钟砍到只剩 3 句倒数 + 系统一句"挪脚也算完成"）；在第二分钟加一点陈屿装模作样"认真研究报名要求"的具体动作（扶了扶根本没戴的眼镜 / 指尖在"主持"那一项上点了一下又抽开）。

- **B2. 节奏 · 结尾"作业本指甲印"段体量偏大 + 偏重**
  - 位置：从"回到家我妈在做饭"到文末。
  - 问题：这是本章的尾声留白，按铁律应 200–400 字。实际这段约 450–500 字，且信息重心从"顾星晚初登场"被拉回到"林知夏细节"上，造成本章**双焦点**——中段是顾星晚首登（重点），末段突然花大篇幅回到林知夏。从"卷一第 005 章"的叙事节奏上讲，005 的任务是让顾星晚立住；林知夏的回扣应该短而有力。
  - 建议：尾段压到 ~300 字。方法：
    - 删掉陈屿两次翻本子 / 三遍追问自己"她今天手指在发抖吗" / "肩膀绷着"这种重复推断。
    - 只保留**一个**具象物证（指甲印）+ **一个**心声（"明天早上稍微看一眼"）。
    - 阮眠出场一句即可（"陈屿哥哥。""嗯。""你今天回来晚。""学校有点事。"——四句封顶，不扩展）。

- **B3. 信息重复 · "她笑" / "夕阳" / "慢半拍"**
  - "笑"在顾星晚段里密集出现：
    - "她笑了一下，笑得很轻"
    - "顾星晚看着我又笑了一下。她笑的时候眼睛弯一下"
    - "她笑的时候眼睛弯一下，只弯一下，就恢复原样"
  - "夕阳" 3 次："夕阳从她肩膀那一侧斜下来"、"米白毛衣在夕阳里往大厅口走了两步"、"夕阳"隐含在"天开始擦黑"的承接。
  - "慢半拍" 3 次："每一个动作都比别人慢半拍"、"慢半拍的那种人"、本句尾再补一句"跟着她慢下来"。
  - 建议：三组意象各保留一次即可，其他替换为具体动作 / 具体声音。

- **B4. 系统段落微节奏 · 方括号段过密**
  - 站三分钟后的大厅对话里，陈屿心声 +（……）+【……对吗？】切换很密。对话本身没问题，但几段后连读容易把读者拉出画面。建议把顾星晚"你不用这样"那段到"……给我，我伸手"之间的系统嘴炮砍一半（系统只留一句即可，其余让陈屿自己内心咬牙）。

- **B5. 文风统一 · 开头"羞辱性打捞"的梗风格**
  - 位置：第 13 行左右 "（……羞辱性打捞。）"
  - 问题：这个词是近年网络梗，风格偏抖音段子。前 4 章陈屿的内心吐槽是冷幽默（"闷骚班长又犯病了" / "我干了什么" / "认命"），属于略带文气的日常吐槽。这里突然蹦一个"羞辱性打捞"，声线跳一下。
  - 建议：换成更陈屿风的 "(……起床气等级：被猫押运到今天。)" / "(被自己的袜子羞辱了。)" / 或者直接删，改一句"(炭头最近越来越像一个收破烂的。)"。

## C. AI 味句段（直接标出原句）

> 按铁律，C 段必须引用原文 + 说明 + 给出改写方向。

- **C1.** 原句："风从大厅外面吹进来，吹动她一小绺头发，贴在脸颊上，又被她伸手轻轻别回耳后。"
  - 问题：标准"女神出场镜头"——风 / 一小绺头发 / 贴脸颊 / 轻轻别回耳后，四件套全家桶。日常章里这种镜头一用就散发偶像剧味。
  - 改写方向：换成**一个动作**即可。
    - 例："她抬手把头发压了压，没理它。"
    - 例："一阵风吹进来，她皱了下眉，不动声色把刘海往边上按了一下。"

- **C2.** 原句："米白毛衣在夕阳里往大厅口走了两步。"
  - 问题：把人换成了衣服 + 抒情镜头（慢动作电影感），且"夕阳"这一章第三次出现。
  - 改写方向："她往大厅口走了两步。袖子太长，手缩在袖口里，走路带一点风。"

- **C3.** 原句："夕阳从她肩膀那一侧斜下来。"
  - 问题：偏抒情铺垫语，日常章可以整句砍掉。保留一句"大厅门口亮一些"即可。
  - 改写方向：删。如需保留光线，改为"大厅靠门口的一片地亮着，靠里这边暗。她站在亮那半边。"

- **C4.** 原句："我心脏'咚'地漏了半拍。"
  - 问题：铁律黑名单。日常章严禁。且第 004 章已用过同款（"我的心跳'咚'地漏了半拍"），连用两章 = 重复模板 + 违禁词双踩。
  - 改写方向：换成**具体动作**。
    - 例："我一只脚已经迈出去，又停下来。"
    - 例："我握车把的手指顿了一下。"
    - 例："我想装作没听见，但我后脖颈先出卖了我——一下绷紧。"

- **C5.** 原句："她每一个动作都比别人慢半拍。慢半拍的那种人，让你不好意思催，也跟着她慢下来。"
  - 问题：典型"换句话再说一遍"AI 病。前一句说完的事，后一句把它换了个主语再重述一遍。
  - 改写方向：留前删后。
    - 例（只保留一句）："她的每一个动作都比别人慢半拍。"
    - 例（把效果落到陈屿身上，避免作者解释）："她慢，我在旁边也跟着慢下来。不好意思催她。"

- **C6.** 原句（结尾段连环）："窗外三月的风一阵一阵。炭头不知道什么时候跳上我的床，卷成一团。我关了大灯，只留一盏小台灯。台灯照着桌面一圈黄。"
  - 问题：四个短句堆叠景物，像一段"网文章末标准落幕镜头"。这种"风 / 猫 / 台灯 / 黄色光圈"组合，读者在别的小说里也见得多。
  - 改写方向：砍两句。只留"只开了一盏台灯"和"炭头蜷在我床尾"两件事即可。或者把台灯改成更具体的东西——"我没开大灯。书桌那盏小台灯还是去年便利店送的，灯罩边上磕掉一小块，光从缺口那里漏出去，打在墙上是个歪的月牙。"（把一个套路意象换成一个具体物件）

- **C7.** 原句："我一抬头：'啥？'" 之后顾星晚的"你不用这样的。" —— **这句口癖本身没问题**（人物档案在列），但她紧接下一句又补"你不用这样为难"——**口癖+复述**。
  - 问题：口癖被作者担心"读者看不出来是她的口癖"再解释一遍。
  - 改写方向：只说一句"你不用这样的。"，停一下，让陈屿自己补脑（"——什么这样？"）。把解释让给陈屿的心声，不让顾星晚自己重复解释自己。

- **C8.** 原句："（我是不是刚刚被人半哄半拐报了名？？？）"
  - 问题：三个问号连用 + 梗式吐槽"半哄半拐"。单独出现可以，但与前面"她怎么知道是三分钟？？" "她怎么会用'对吗'？？？" 三段连续三问号三连，情绪被拉爆。日常章情绪应在"冷" + "无奈"。
  - 改写方向：保留这一句（作为结束感最好的那一句），**前面两段的三问号全部降级**——改成"（……她怎么知道是三分钟。）"不加问号，反而更有"陈屿被击中后装没事"的调性。

- **C9.** 原句："（——'字也行'三个字杀伤力怎么这么大。）"
  - 问题："杀伤力"是近年网络词，用一次尚可；但它与上面 B5 提到的"羞辱性打捞"叠加，日常章语言层会偏梗。保留一个、砍一个即可。建议保留这个（"字也行"是本章最有味道的一处），砍开头的"羞辱性打捞"。

## D. 修改建议（不是泛论，要具体）

### D.a 中午广播段（~150 字补扩 → 合计 3,800+）

**补写落点**：食堂二楼排队到打饭窗口的空档。
**必含具象要素**（润色口味）：
- 听觉：打饭勺碰饭盆那声"咣"、阿姨吼"下一个"、前面人在甩零钱找硬币、后面有人在边排队边背单词（混在嘈杂里听不清背的是英语还是日语）。
- 位置：头顶斜上方那个老式木壳广播—— **必须写它的物理状态**（"木壳广播外壳糊了一层灰，底角那颗螺丝松了一颗，挂得有一点斜"）。不写成"声音像春风从喇叭里飘出来"。
- 陈屿第一反应：**不**是"心里一动"；**是**"我端饭盆的手顿了半秒，差点把勺杵到汤碗里去"。

**建议插入位置**：第 20–50 行之间（从"食堂二楼排队的时候……"展开）。

### D.b 下午去公告栏路上装逼心理战（~150 字）

**必含**：
- 两段陈屿自己的心理战——走快了像急着报名，走慢了像在犹豫。
- 一段绕路动作——"我绕到饮水机那边装接水，接了半杯没喝，把杯子搁饮水机旁边就走了。" （后面一句可以回扣："那杯水第二天被清洁阿姨倒了，我再没见过。"——不写进正文，但心里可以冷一下）。
- 系统冷嘲 1–2 句：
  - 【本系统建议，您正常走路就行，对吗？】
  - 【您绕那台饮水机两圈，是在熟悉撤退路线吗，对吗？】

**建议插入位置**：第 120 行前后（"我下楼，走到一楼大厅"之前）。

### D.c 顾星晚叫住陈屿那一刻的画面（~100 字）

**必须做的事**：
- **去滤镜化**：不要再出现"夕阳 / 风吹头发 / 光打在她身上"。
- **具体细节替换**：
  - 光：不是夕阳，而是"大厅靠门的高窗漏进来一片亮，照到地上一个歪的梯形，她正好站在那个梯形的边上"。
  - 她手里的东西：**牛皮色文件夹**，边缘磨损；夹子弹簧没压紧，里面 A4 纸露出半寸。
  - 声音方向：从陈屿背后**偏左**传来（方位具体）。她叫"同学"的这声不是"软糯"，而是"比播音的时候还更轻一点，像她自己也在估计要不要叫"。
- **保留**的好句："她先'嗯'了一声，像给自己打了个腹稿。"（这句是本章顾星晚最 in character 的一句，务必留）

**建议插入位置**：第 215–240 行（"身后传来一个声音——'同学。'"这里展开）。

### D.d 填报名表的过程（~150 字）

**必须包含的四个动作 / 物证**：

1. **她递笔的具体动作**：
   - "她把笔帽拧下来，拿着笔帽那头，笔尖朝她自己，笔尾朝我。"
   - （这个动作是"教小孩怎么握笔"的礼貌递法——顾星晚的"会照顾人"就从这一个动作体现，不用写"她很会照顾人"。）

2. **报名表正反**：
   - 正面：粗体黑色标题"云屿一中广播站招新报名表（第二批）"，下面是姓名/班级/意向岗位/特长/一句话自我介绍五行表格。
   - 反面：空白，右下角印一行小字"编号 07-23"（07 代表广播站、23 代表第 23 张——留一个之后可以被陈屿偶然翻到的细节伏笔）。

3. **陈屿写字比平时小心一点**（**关键回扣**）：
   - 种子：第 004 章陈屿本子上写"认命"被他涂成一坨煤——他自己知道自己字丑。
   - 回扣方式：
     - "我写'陈'字的时候，那一捺比平时拉得短一点。"
     - "我写'屿'字最后一个竖勾，从平时的随便一勾改成规规矩矩收了一下。"
     - "我没抬头，但我知道她在看我写。"
   - **不要**写"我想把字写得好看点给她看"——这是内心动机剧透。留给读者自己看出来。

4. **顾星晚的点评**（**保留正文原句，只加一个动作**）：
   - 原句："你普通话确实不错。""字也行。"
   - 建议加一个她手上的动作——"她说'字也行'的时候，指腹在表的右下角'编号 07-23'那里轻轻按了一下。"（这是把 2 里埋的编号种子再埋一层。）

**建议插入位置**：第 380–410 行（"姓名：陈屿。班级：高一（7）班。"那一段）。

### D.e 骑车回家冷嘲（~100 字）

**必须冷不抒情**。三段具体吐槽方向，建议保留两段：

- "（合着'普通话好'这标签是老陆甩给我的。）"
- "（老陆上午那节课明明还在讲二次函数。他什么时候有空跑二班办公室去'点'我的。）"
- "（下次他再叫'你说是吧陈屿同学'，我一定反问他'是吗，陆老师'。）"——这一段建议落在路过灯下便利店那一刻，陈屿头都不回地蹬了两脚车。

**可以带一句**把便利店老板娘的存在做个**沉默铺垫**（不用扩写，一眼带过即可）：
- "便利店老板娘在玻璃里擦东西，金丝眼镜转过来看了我一眼，没叫我。她认识所有人，但从不主动招呼。"
- （这是为卷一第 016 章"灯下便利店外长椅"那场顾星晚请陈屿喝水做的远端铺垫——老板娘的"认识所有人"人设提前一锤。）

**建议插入位置**：第 470–490 行（"我推着车出校门的时候，天开始擦黑"之后）。

## E. 风险预警（润色视角）

- **E1. 顾星晚"温柔滤镜"固化风险**
  - D.c 补扩如果管不住手，"夕阳 / 风 / 头发"还会回来。建议：修订 subagent 写完 D.c 之后**自检一遍**——任何出现"夕阳 / 斜阳 / 余晖 / 风吹 / 发丝 / 眼神温柔 / 笑容浅浅"的词汇，全部换成具体动作 / 具体道具。

- **E2. 梗密度偏高的风险**
  - 本章已经有"羞辱性打捞""杀伤力""半哄半拐""这波"等偏网感词汇。D 段补扩再加字时，不要再加新的梗词。陈屿的声音应该是冷 + 克制 + 偶有一两句毒；不是梗手本人。

- **E3. "心跳漏了半拍 / 一拍"的防复发**
