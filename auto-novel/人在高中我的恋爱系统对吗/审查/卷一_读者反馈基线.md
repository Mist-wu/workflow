# 卷一（第 001–010 章）读者反馈基线

> 生成方式：按 `framework/05_批次化写作工作流.md §7.5` 读者模拟协议，对前 10 章各派 3 个 subagent（α 追更挑剔党 / β 入坑三章党 / γ 预判党），共 30 份独立报告。
> 本文件是**基线档案**，不是二次修订令。是否修订由主 agent 基于阈值判断（α/β ≤ 5 必修 / γ 三预测全中必改结尾）。

## 二、γ 预判党命中率（套路雷达）

γ 每章给 3 条"下一章预测"，命中率越高 = 本章套路越标准。对照正文看：

| 本章 | 对下一章预测 | 命中验证 |
|-----|------------|---------|
| 001 γ 预测 002 | "说早 → 对方冷淡 → 首笔币到账 / 弹出低好感度 / 周胖察觉反常" | 002 确实是说早 + 好感度 35（确实低）+ 郑维不是周胖但有"察觉"类插入 → **2/3 命中** |
| 003 γ 预测 004 | "数学课掉笔 / 阮眠借口来门口 / 林知夏冷不丁问家里事" | 004 是数学课笔滚到郑维脚边（半命中），阮眠未登门，林知夏没发问 → **1/3 命中** |
| 006 γ 预测 007 | "放学广播站报到 / 林知夏新便签 / 走廊两线交叉" | 007 是广播站报到（命中），林知夏以"嘱咐"开场（半命中），两线交叉发生在结尾"播报员=顾星晚" → **2/3 命中** |
| 008 γ 预测 009 | "苏檐受伤 / 陈屿站起暴露立场 / 林知夏周六堵他 / 翻书配好感度" | 009 是苏檐磕破膝盖 + 主角递纸巾（半命中），周胖大呼小叫（命中），林知夏未堵，翻书未发生 → **1.5/3 命中** |
| 010 γ 预测 011 | "林知夏翻到回画眼镜 + 上课刁难 / 周胖课间八卦触发吃味 / 系统播报林知夏好感度 +2~+4" | 011 尚未写 → **未验证**（建议写 011 时刻意避开这三条） |

**结论**
- 平均命中率 ≈ **50%**——属于"读者能猜到一半，但还留一半反转"的舒适区。
- 但 γ 对 **010→011** 的 3 条预测都非常具体、非常套路，如果不反着写，011 会被预判党直接打成俗套。**011 写作时必须回避至少 2 条**。

## 四、亮点记录（写作时记住读者真正会记住的东西）

| 章 | 记忆点（读者自发引用） |
|---|---------------------|
| 001 | 系统"跑调唱《同桌的你》威胁"——去金手指感 |
| 002 | "'就一句早'这四个字，您已经在心里说了十七次" |
| 003 | "炭头全程无视阮眠的手从她旁边绕过去" |
| 004 | 结尾"我又没喜欢她，结果没捡成我还不爽" |
| 005 | 顾星晚偷系统口癖："三分钟，对吗？"（被所有三人格同时点名） |
| 006 | 林知夏画的蚂蚁是四条腿——"画得方便认" |
| 007 | "——顾——星——晚。"三字报幕压在 D 级任务落地 |
| 008 | 苏檐"用手拿。就这么简单。" |
| 009 | 苏檐磕破膝盖按着地要罚球 + 终场中线小拳头"你给我等着" |
| 010 | 本子最后一页回画的眼镜 |

**规律**：所有三人格一致点赞的记忆点都具备三个特征——
1. **动作**而非心理（画蚂蚁、递纸巾、比拳头）
2. **对系统 / 金手指的反写**（顾星晚偷口癖、跑调唱歌威胁）
3. **克制到留白**（"用手拿。就这么简单。"三字结句）

**给写作 subagent 的产品化启示**：每章脑暴定稿的"1 画面 + 1 动作 + 1 金句"至少要有一项满足上面三种特征。

## 五、触发下游动作

### 必须执行（在批次 0 修订前）
1. **010 章 AI 味硬禁用清零**（已由 `scan_ai_templates.py` 抓到 2 处，修订 subagent 必改）。
2. **011 章脑暴必须避开 γ 对 010 的 3 条预测**：不要让林知夏在周一早读翻本子刁难主角；不要让周胖当"触发吃味的八卦源"；不要让系统立刻播报林知夏好感度变动。

### 建议执行（写入风险清单）
3. **系统台词密度总控**：给后续章节加一个隐性上限——每章系统话 ≤ 5 次（长任务算 1 次），"本系统 XXX 部"一类梗全卷累计 ≤ 3 次。
4. **β 视角提示语机制**：跨章回扣首次出现，必须带 ≤ 8 字的微提醒。写进 `framework/03_风格与创作铁律.md` 的"跨章连续性检查清单"第 8 条候选。
5. **女角色登场节奏**：卷一 011–015 不要让三位以上女角色在同一批内出现"推进事件"；至少留一章纯男生群戏（周胖 / 老陆 / 郑维）做缓冲。

### 观察项（下批次验证）
6. γ 预判命中率是否继续保持 50% 左右；若上升到 66%，说明排布在趋同化。
7. 全书均分是否保持在 7.2–7.8 区间；若单批次滑落到 7.0 以下，触发 Ideator 重派。
