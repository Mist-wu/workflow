## §2 必修清单（100% 执行）

### A1【硬校验】苏父台词 3 行 → 压回 2 行

- **位置**：第 337–339 行（陈屿告别时苏父说"嗯"）
- **当前**：
  ```
  我回头朝厨房那边："叔叔，我先走了。"

  她爸从厨房里探出半张脸，手里举着一个滴水的碗。

  "嗯。"

  就这一声。他又缩回厨房去洗他的碗。水龙头哗哗响起来。
  ```
- **改为**（删 337 行的"嗯。"+ 联动改 339 行）：
  ```
  我回头朝厨房那边："叔叔，我先走了。"

  她爸从厨房里探出半张脸，手里举着一个滴水的碗。他朝我点了一下头，又缩回厨房去洗他的碗。水龙头哗哗响起来。
  ```
- **理由**：开章卡 §3 + §5 硬约束苏父台词 ≤ 2 行（"行。" + "多陪她，她那脾气。"已用满）。送别那声"嗯"超出。改成"点头"动作不破坏苏父寡言人设，反而更符合"远洋船员久不在家"的疏离感。

### A2【AI 味-轻】第 239 行叙述者代读者总结

- **位置**：第 239 行
- **当前**：
  ```
  她问得自然，像随口问的，没有别人家长那种"成绩 = 钩子"的紧绷感，更像是问一句"今天天气怎么样"。
  ```
- **问题**：叙述者用"分析+对照"代读者下结论，破坏第一人称冷感视角的"动作承担情绪"风格。
- **改为**（保留陈屿冷感视角的克制感）：
  ```
  她问得不像别人家长那样。
  ```
  或保留更具体的对照感：
  ```
  她那语气像是在问明天会不会下雨。
  ```
- **由修订 subagent 选其一**。

### A3【节奏-轻】第 199 行苏父出场句式与第 123 行重复

- **位置**：第 123 行 + 第 199 行
- **当前**：
  - L123：「她爸不知道什么时候从沙发上下来，走到了厨房门口。他在门框那儿站了一会儿……」
  - L199：「她爸不知道什么时候从沙发上又起来了，走到厨房门口。他没进来，只在门框那儿站了一会儿。」
- **问题**：两次出场写法几乎相同（都是"沙发→厨房门口→站门框"）。
- **改为**（第二次出场换写法，让动作有差异）：
  ```
  她爸又从沙发那边过来。这次他没去厨房门口，停在餐桌侧面那张木椅边上，伸手摸了一下椅背的木头，又收回手。
  ```
  或更短：
  ```
  她爸第二次过来时没站到门框那儿，绕到餐桌侧面，伸手在椅背木头上摸了一下，又收回手。
  ```
