# 世界观与系统设定

## 一、世界观
- **时代背景**：近未来的现代都市，与现实中国高中生活几乎一致。手机、地铁、便利店、外卖、B 站、微博、QQ、微信都在，但做过软处理（用"蓝信""小破站""鸟博"之类替代，避免真实商标）。
- **地点**：东南沿海省辖市，"云屿市"，濒海。主角就读的学校为"云屿一中"（简称"云一"）。三年制公立高中，重点班 + 普通班 + 实验班（艺体）。
- **时间线**：故事始于主角高一下学期开学第一周（三月一日星期一，天气晴偏冷）。
- **基调**：现实主义底色 + 一层系统喜剧。没有超能力、没有异世界、没有重生。唯一的"非现实"就是那个系统，而它本身也像个混账打工人。

## 二、系统设定
### 2.1 本体
- **名称**：高中恋爱辅助系统 ver.0.8（没错，永远是 0.8，永远"测试版"）。
- **登场方式**：主角在自家阳台晒被子时被一只黑猫绊倒，后脑勺磕在空调外机上，醒来后脑中多了一个娘化的电子音。
- **开局台词**：
  > "尊敬的宿主，您已成功绑定《高中恋爱辅助系统》，按照校规，您在三年内需达成基础恋爱指标，对吗？"
  主角第一反应："不对。"
  系统："好的，记录下来，宿主对初始条款表示认可，对吗？"
  主角："也不对！"

### 2.2 核心机制
1. **任务系统**
   - 系统不定期发布任务，每条任务末尾必带"对吗？"。
   - 任务分为：**日常任务（D 级）** / **支线任务（C 级）** / **主线任务（B 级）** / **隐藏任务（A 级）** / **终极任务（S 级）**。
   - 任务奖励分两类：
     - **好感度反馈**：让主角看到某位女角色对他的当前好感数值（0–100）。
     - **生活币**：可以兑换实物（一张篮球、一瓶墨水、一次免作业卡）。系统坚称生活币"只能用于对恋爱没有直接帮助的奖励"，主角怀疑系统在偷懒。
2. **惩罚机制**
   - 拒绝任务三次，系统会进入"罢工模式"：主角只能听到电子音反复播放一首跑调的《同桌的你》，持续 24 小时，直到他妥协。
   - 失败任务会扣生活币，但不会扣血、不会要命。系统的底线写得很清楚："本系统不伤害宿主本体，对吗？"
3. **好感度说明**
   - 好感度 ≥ 60：明显示好。
   - 好感度 ≥ 80：告白成功率显著提升。
   - 好感度 = 100：系统判定"可以确立关系"。
   - 但系统特别强调：**数值仅供参考，现实中的她们并不知道这个数字。**
4. **系统不能做什么**
   - 不能给主角开挂（不给学习加成，不给身体素质加成）。
   - 不能直接操控他人。
   - 不能透露角色秘密（系统会说："涉及隐私，对吗？"）。
   - **不能被除主角外的任何人看到或听到。**
5. **系统的"小心思"（重要伏笔）**
   - 系统 ver.0.8 是"测试版"，它的上级单位一直在催它交报告。
   - 随着剧情推进，系统会在第 5 卷开始出现"人格化"倾向——偶尔说"我觉得"，偶尔替主角挡锅。
   - 终卷（第 10 卷）揭示系统的真身：不是什么上位文明，也不是重生者，而是……（见总大纲终卷）。

### 2.3 任务示例（风格定锚）
- **D 级**：在今天放学前，主动和同桌说一句包含"谢谢"的完整句子，对吗？
- **C 级**：在周四体育课自由活动时间，把篮球传给周围三米内好感度最高的人，对吗？
- **B 级**：在文化节当天，为至少两位女同学拍一张她们会笑着发朋友圈的照片，对吗？
- **A 级**：在期末考试结束当晚，在校门口的那家便利店门口，如果有人在等你，你不可以假装没看见，对吗？
- **S 级**：在你人生中最重要的那一天，做出一个不会让十年后的自己发短信骂你的决定，对吗？

### 2.4 系统口头禅（全书反复出现）
- "对吗？"
- "本系统仅做辅助建议，对吗？"
- "这是宿主自己选的，对吗？"
- "哦。"（只有在主角明显做错时，系统会平淡地"哦"一声，然后什么都不再说。）

## 三、学校与场景
- **云屿一中**：依山面海，两栋教学楼（"启智楼""明德楼"），一座老图书馆，一片大操场，一栋新落成的科学馆。
- **食堂**：分两层，一楼大锅饭，二楼小炒。主角最爱二楼的蛋炒饭。
- **便利店**：校门口对面巷子里那家"灯下便利店"，老板娘戴金丝眼镜，认识所有在校生，会给人记账。
- **班级**：高一（7）班——全校唯一一个"文理兼修实验班"，人比较怪，但成绩不差。
- **社团**：文学社、广播站、男篮、女篮、动漫社、天文社。主角在第 1 卷被强行塞进广播站。

## 四、校园大事件时间线（决定十卷主线）
- **卷一（3 月）**：高一下学期开学 + 春季运动会。
- **卷二（4 月）**：月考 + 清明返校 + 社团招新第二轮。
- **卷三（5 月）**：五一文体周 + 合唱比赛。
- **卷四（6 月）**：期末 + 暑假前一周（全员大合照）。
- **卷五（7–8 月）**：暑假（海边打工、家教、补课、夏令营）。
- **卷六（9 月）**：高二开学 + 分科 + 新学期分班。
- **卷七（10 月）**：秋季运动会 + 国庆假期。
- **卷八（11 月）**：期中 + 校庆文化节。
- **卷九（12 月–1 月）**：期末 + 元旦晚会 + 一个关键冬夜。
- **卷十（2 月–3 月）**：寒假 + 高二下学期开学 + 系统"毕业"。
