# 风格与创作铁律（subagent 必读）

> 本文件规定所有章节正文的**文风、格式、单章结构、禁忌**。任何 subagent 写作前必须完整阅读并遵守。

## 一、文风
- **人称**：第一人称（陈屿视角）。
- **基调**：轻喜剧。幽默来源于"他吐槽系统，而系统毫不在意"，而不是来源于刻意抖包袱。
- **节奏**：对话 > 心理描写 > 环境描写。大段环境描写最多两段，一段不超过 100 字。
- **密度**：
  - 对话占比约 45%–55%
  - 心理 / 吐槽占比约 25%–30%
  - 动作 / 环境 / 过场占比约 20%–25%
- **句长**：短句为主，整段读起来有节奏。长句出现时用于抒情或关键转折。
- **视角限制**：陈屿看不见的东西、听不到的话、不知道的事，不能在正文中呈现。偶尔可以用"后来我才知道"倒叙，但每章最多一次。

## 二、系统出场规范
- 系统每次发话，单独成段，**用方括号包裹**，末尾必带"对吗？"（或变体"是吗？""可以吗？"在极少数情况下使用，全书不超过 20 次）。
  示例：
  ```
  【宿主，下一节是体育课，请在自由活动时间把那个篮球传给苏檐，对吗？】
  ```
- 主角内心回复系统时，用 **"（……）" 圆括号包裹** 的心声段表达：
  ```
  （不对。）
  （我凭什么听你的。）
  ```
- 系统"说人话"时（人格化发展后）依然用方括号，但语气会软。
- 系统沉默时用：
  ```
  【……】
  ```
  或什么都不写，切忌反复说"系统没有回应"。

## 三、单章结构（模板）
每章结构建议：
1. **开篇钩子（150–300 字）**：一个画面、一句吐槽、一段对话，让读者立刻进入。
2. **事件推进（2000–2500 字）**：本章承担的剧情任务（看细纲）。
3. **关系变化（800–1000 字）**：本章与哪位角色的互动，好感度有无变化，**用系统提示播报出来**。
4. **尾声留白（200–400 字）**：一个余味。可以是一句对话、一个动作、一段景物、一条晚风。
5. **章末小结**（**文件最后一行**，不计入正文字数）：
   ```
   ————本章字数：约 4100 字————
   ```

## 四、章节文件格式
每章独立存为 `.txt`，命名格式：
```
第001章_章节标题.txt
```

文件首行 = 章节标题，独占一行：
```
第一章 炭头把我撞进了系统
```

空一行后正文开始。正文段落之间空一行（全书统一空一行，便于阅读）。

文件最末一行必须是：
```
————本章字数：约 XXXX 字————
```

## 五、用语铁律
- 全书避免"她羞得像一只煮熟的虾"这类程度过强、土味过重的比喻。
- 避免"狗血三件套"：车祸、失忆、绝症。**本书任何角色不得有绝症设定**。
- 避免"**她就是这个世界上最美的女孩**"这种绝对化抒情。
- 避免"蛋饼一般的小嘴""饱满的胸脯"等身体部位的具象化描写。
- 情绪描写尽量走克制：与其说"她非常生气"，不如说"她把笔帽咬出了齿痕"。

## 六、方言与口语
- 本书可以偶尔出现江浙沪口语（"侬""阿拉"等不要用，因为是东南某省辖市，但"小伙子""噶""蛮"可以）。
- 周胖说话可以偏口语、略带粗粝（但不能脏）。
- 老陆的东北口音在课堂上偶尔冒出来（"你这个同学啊……"）。

## 七、系统口癖复用（关键）
每 2–3 章，系统必须说一次"对吗？"结尾的任务；整本书系统任务数量约 150 条左右，覆盖绝大多数章节但非每章。没有系统任务的章节，就让系统"沉默"或"偶尔冒一句短评"。

## 八、跨章连续性检查清单（subagent 写作自检）
每写完一章，必须快速核对：
1. 本章提到的所有角色，是否与人物档案一致（姓名、身高、口癖、好感度方向）？
2. 好感度变化是否合理、有显式播报？
3. 系统本章是否该出场，是否给出任务？
4. 本章是否承接上一章结尾的画面、悬念或对话？
5. 本章结尾是否给下一章留了钩子？
6. 字数是否在 3800–4400 之间？
7. 是否没有暴露最终结局、没有剧透后面章节的关键伏笔？
8. **β 视角微提醒（跨章回扣铁律）**：本章任何**跨章回扣**（上章或更早才登场/发生过的人、物、事件、台词）**首次出现时**，必须带一句 ≤ 8 字的微提醒，让"入坑三章党"读者能立刻想起是谁/是什么。  
   - 触发条件：该元素在本章之前**最近 3 章内没出现过**，或读者可能因时间线太远而忘掉。
   - 微提醒形式举例：
     - 人物："郑维（班长）" / "那个第一次把笔塞她桌上的郑维"
     - 事件："昨天扫蚂蚁那事" / "上周广播站那稿" / "在便利店撞见的那瓶乌龙茶"
     - 道具："她画了小人的那页作业本"
   - **反例**（禁止）：直接写"她前天在大厅里说过一次"而不交代是什么大厅、什么话。
   - 在对话里也算，宁可让角色自己补半句："——就是上回给我画蚂蚁的那张 A4。"
   - **抒情章 / 高能章**可以例外（这些章读者情绪在线，轻度跳跃不影响），但日常章必须守。

## 九、字数保证策略
- subagent 写作时，**先写一个完整章节**，再回头检查字数。
- 如果字数不够：在对话间增加"心理副歌"、增加"系统吐槽"、扩写一段环境描写、补一段陈屿与周胖的闲聊。
- 如果字数超标：先砍环境描写、再砍非关键角色台词。**主线对话一定不能砍**。
- 一律不允许用"（此处省略两千字）""（后面略）"之类的方式糊弄。

## 十、写作禁忌（必读）
- 不得改写人物档案里已定的性格与关系。
- 不得让系统"突破"世界观文件里的"系统不能做什么"。
- 不得临时加入主角的"隐藏身份""家族秘密""低调富二代"等爽文元素——**陈屿就是个普通高中生**。
- 不得在非终卷透露系统的真身。
- 不得让任何女角色"倒贴式告白"——所有情感推进必须基于真实互动和时间。

## 十一、抒情阈值
全书 250 章中，允许"认真抒情"（非喜剧语气，真正触动人心那种）的章节不超过 20 章，且集中在：
- 卷四末尾（高一结束前的合照）
- 卷五海边夜 + 卷五末尾
- 卷六顾星晚出国
- 卷八顾星晚回国
- 卷九冬夜关键一章
- 卷十毕业 / 表白 / 真结局 / 尾声

其余章节以日常、轻喜、小温暖为主。不要每章都抒情。

## 十二、审查机制（必看）
每一章写完之后，**必须**交给两个审查 subagent 依次审核：
1. **硬校验 subagent**：只审剧情连续性、设定一致性、人物一致性、动机合理性、伏笔回收、风险预警。
2. **润色审查 subagent**：只审节奏、信息重复、文风统一、去 AI 味、可读性。

完整的审查维度、强制输出格式（A 硬错误 / B 软问题 / C AI 味句段 / D 修改建议 / E 风险预警）、三份提示词模板（硬校验 / 润色 / 修订），全部见 **`framework/04_审查工作流.md`**。写作 subagent 自己**不能**跳过审查直接落盘。

AI 味自检项（写作时自己先过一遍）：
- 不出现"她不由得""嘴角微扬""心跳漏了一拍"（日常章禁用）"空气仿佛凝固""不知过了多久""刹那间""莫名其妙地""她眼中闪过一丝"。
- 不用"就这样，……"做总结式收尾。
- 不用"静静地""默默地""悄悄地"三连叠词。
- 不用"眼睛像星星""笑容像阳光""声音像风铃"这类俗套喻体。
- 排比最多两并，不三并。
- 心理描写不做"换句话再说一遍"。
