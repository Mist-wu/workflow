### 1.4 节奏硬禁条款（v3.1，2026-04-26 复盘加入）

> 背景：批次 002–004 主 agent 自写章节出现"破折号 + 单字短行 + 内括号心声"过载，
> 中文实际字数大幅低于 DoD（3800–4400），章末"约 XXXX 字"标注与实测偏差 > 1500。
> 任意一项命中即记红，由 `scripts/check_rhythm.py` 强校验，**与 H-AI 同等优先级**。

| ID | 触发条件 | 阈值 | 校准依据 |
|----|--------|-----|---------|
| **H-RHYTHM-DASH-OVERFLOW** | 单章 `——` 总数 / 中文字数 | > 2.5% | 010-014 基线最劣 1.72%（012）; 退化最佳 3.32%（018） |
| **H-RHYTHM-SHORT-LINE** | 单/双字独立成段（中文 ≤ 2）/ 总段数 | > 25% | 010-014 基线最劣 23.9%（012）; 退化最佳 22.9%（018） |
| **H-RHYTHM-INNER-PAREN** | 段首"（——XXX）"心声内括号 / 中文字数 × 1000 | > 12.0/千字 | 010-014 基线最劣 11.6/千字（012）; 退化最佳 10.3/千字（016） |
| **H-RHYTHM-LOW-DENSITY** | 平均段长（总中文字数 / 总段数） | < 8.5 字 | 010-014 基线最劣 9.08（011）; 退化最佳 7.34（023） |
| **H-RHYTHM-FAKE-COUNT** | 末行"约 XXXX 字"与实测偏离 | > 150 | 与 `check_dod.py` DoD 7 同口径 |

**抒情豁免章不豁免本节**：节奏不是抒情，是排版。

**写作 subagent 的应对要求**：
- 心声/内心独白以**段落**承担（≥ 30 字一段），不再用"（——XXX）"短括号嵌套；保留极少数关键节点（每章 ≤ 3 处）。
- 破折号 `——` 改用**完整句子**或"，"承接；只在"对话被打断"或"语气陡转"时使用。
- 单字"嗯。""哦。"对话不堆叠超过 3 行；超过则改为合并段落或加动作描写。
- 写完一章自检：跑 `python3 scripts/check_rhythm.py NNN`，未 PASS 不得交稿。

## 二、软限额（整章允许，但超阈值记红）

### 2.1 "心跳漏了一拍"
- 全书 250 章累计不超过 60 次；单章不超过 1 次；日常章禁用。
- 抒情章（见 `03_风格与创作铁律.md §十一` 的 20 章）最多 3 次。

### 2.2 叠词三连
- 连续 3 个 "静静地 / 默默地 / 悄悄地 / 缓缓地 / 轻轻地" 叠词 在同段出现即记红。
- 正则：`(?:[静默悄缓轻]地.*?){3,}`（同段内）

### 2.3 "她不" / "他不" 三并排比
- 正则：`她不\S{0,8}[，。]?\s*她不\S{0,8}[，。]?\s*她不`
- 同样规则适用于"他不"。

### 2.4 程度副词堆砌
- 同段内 "非常/十分/格外/极其/特别" 累计出现 ≥ 4 次记红。

## 三、句式模板（正则级审查，必标原句）

| ID | 正则（Python） | 说明 |
|----|--------------|-----|
| T01 | `她的(?:眼|眼睛|眼眸)里闪过.{1,8}` | "她眼中闪过一丝 X" |
| T02 | `仿佛整个世界.{0,10}静止` | "那一刻整个世界仿佛静止了" |
| T03 | `复杂的情绪.{0,10}(?:涌|浮|泛)` | 过度解释情绪 |
| T04 | `既有.{1,10}又有.{1,10}还有.{1,10}` | 三段情绪排比（过度解释） |
| T05 | `像是.{0,4}又像是.{0,6}` | "像是 X 又像是 Y" 虚化比喻 |
| T06 | `(?:轻轻|悄悄|默默|静静)地[^。]{0,20}(?:轻轻|悄悄|默默|静静)地` | 同段叠词 |
| T07 | `(?:一|某)个.{0,6}的(?:瞬间|刹那|瞬息)` | "某个微妙的瞬间" |
| T08 | `不经意间` | AI 最爱用的虚化时间副词 |
